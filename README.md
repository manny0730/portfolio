# Manuel Toledo | 3D Artist & XR Developer Portfolio

This is the source code for my personal portfolio website, designed to showcase my work in **3D Environments**, **XR Development**, **Game Design**, and **Short Films**.

The site is built as a modern, high-performance Single Page Application (SPA) focusing on immersive visuals and smooth interactivity.

## 🚀 Tech Stack

- **[React](https://react.dev/)**: Core framework for building the UI.
- **[Vite](https://vitejs.dev/)**: Next-generation frontend tooling for fast builds and hot module replacement (HMR).
- **[Tailwind CSS](https://tailwindcss.com/)**: Utility-first CSS framework for styling and responsive design.
- **[Framer Motion](https://www.framer.com/motion/)**: Library for production-ready animations (used for the gallery lightbox and page transitions).
- **[Spline](https://spline.design/)**: Used for the interactive 3D background in the hero section.
